# Cursor skills path

Cursor discovers skills from [`.claude/skills/`](../.claude/skills/) per [Cursor Agent Skills — Skill directories](https://www.cursor.com/docs/context/skills).

**Phase orchestrators** (`/plan`, `/build`, `/review`, `/ship`) are defined once under `.claude/skills/` — do not duplicate here unless you intentionally fork a phase for Cursor-only behavior.
